# 📌 Project Overview

The **Banking Information System** is a console-based Java application that simulates basic banking operations such as:

✅ User Registration  
✅ Login Authentication  
✅ Deposit Money  
✅ Withdraw Money  
✅ Fund Transfer  
✅ Account Statement  
✅ Transaction History  
✅ Account Management  

This project is developed using **Core Java**, applying real-world banking workflows and object-oriented programming concepts.
